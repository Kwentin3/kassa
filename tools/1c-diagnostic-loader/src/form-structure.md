# Структура внешней обработки `1C_HTML_SHELL_DIAGNOSTIC_LOADER`

Дата: 2026-05-19
Статус: source draft для ручной сборки в 1С Designer/EDT

## Почему нет готового `.epf`

В текущем workspace нет целевой 1С-базы, проекта EDT и проверенного сценария сборки внешней обработки. Локальное наличие runtime `1cv8` не равно корректной сборке `.epf`.

Поэтому этот пакет содержит исходники и структуру формы для 1С-программиста. Не имитируйте `.epf`; соберите внешнюю обработку в целевой 1С-среде и проверьте поведение HTML-поля на реальном клиенте.

## Рекомендуемый объект

Создать внешнюю обработку:

```text
1C_HTML_SHELL_DIAGNOSTIC_LOADER.epf
```

Синоним:

```text
1C HTML Shell Diagnostic Loader
```

| Имя | Тип | Назначение |
|---|---|---|
| `HTMLАдрес` | Строка, неограниченная | Данные для элемента `Поле HTML-документа`; сюда записывается URL диагностики. |
| `ДиагностическийURL` | Строка, неограниченная | Базовый URL, по умолчанию `https://kassa.speechbattle.com/diagnostics/1c-html-shell`. |
| `RunId` | Строка | Идентификатор запуска диагностики. |
| `TerminalLabel` | Строка | Безопасная метка терминала. |

| `ТипКлиента` | Строка | `thin`, `thick`, `web` или `unknown`; можно заполнить вручную. |
| `ИмяКонфигурации` | Строка | `Retail`, `UNF`, `UT`, `custom` или `unknown`. |
| `ВерсияКонфигурации` | Строка | Версия конфигурации, если можно безопасно указать. |
| `РежимСовместимости` | Строка | Если известен. |
| `ПоследняяКомандаJSON` | Строка, неограниченная | Последняя входящая команда для отладки. |
| `ПоследнийОтветJSON` | Строка, неограниченная | Последний ответ loader-а. |
| `ЖурналСобытий` | Строка, неограниченная | Человеко-читаемый журнал. |

## События HTML-поля

Подключить доступные в вашей версии платформы события HTML-поля к обработчикам из `DiagnosticLoaderFormModule.bsl`.

Минимально попробовать:

- `ПриНажатии` → `ПолеHTMLДокументаПриНажатии`;
- событие перехода/навигации, если доступно → `ПолеHTMLДокументаПриПереходе`;
- событие завершения формирования/загрузки документа, если доступно → `ПолеHTMLДокументаДокументСформирован`.

Названия событий и состав `ДанныеСобытия` зависят от версии платформы, клиента и режима совместимости. Это нужно проверить на целевой базе.

## Важное ограничение текущей web-страницы

Текущая diagnostic page уже содержит `window.DiagnosticHarness`, но активные HTML → 1С bridge-probes могут потребовать парного обновления web-страницы или временно injected hooks. Команда `УстановитьHTMLHooks` в модуле формы показывает безопасный draft такого подхода, но его нужно проверить в целевой 1С-среде.
